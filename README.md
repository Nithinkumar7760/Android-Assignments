## 📌 Sections Overview

### 1. [Level 1: Kotlin Fundamentals](./Level-1/)
Contains solutions for foundational Kotlin programming assignments covering:
- **Assignment 1:** Basic syntax, control flow, functions.
- **Assignment 2:** Collections and data structures.
- **Assignment 3:** Object-Oriented Programming (Classes, Inheritance, Interfaces).
- **Assignment 4:** Advanced Kotlin features and lambdas.
- **Exception Handling:** Robust error handling and custom exceptions.

### 2. [Level 2: Student Organizer App](./Level-2-StudentOrganizer/)
A complete **Jetpack Compose** & **Material 3** Android mobile application built with:
- **Declarative UI Layouts:** Clean Column, Row, Box, Scaffold, and Card layouts.
- **5 Complete Screens:** Dashboard, Assignments List, Student Profile, Settings, and Add Assignment.
- **Modular Composables:** `AppBar`, `BottomBar`, `CourseInfo`, `AssignmentCard`, `StudentProfile`, `AssignmentForm`.
- **Form Validation & State Hoisting:** Reactive form inputs with field validation.
- **Navigation Graph:** Seamless multi-screen navigation using Jetpack Navigation Compose.

👉 For full app documentation, see the [Level 2 README](./Level-2-StudentOrganizer/README.md).
